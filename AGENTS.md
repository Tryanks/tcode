# Repository instructions

Before changing or reviewing code or tests, deciding what to do about a
failing test or one met in the area of a change, or investigating a problem
that may be a dependency's, read [CONTRIBUTING.md](CONTRIBUTING.md).
Its **Principles** section is the only maintainer-authored text in this
repository; everything else is derived from it and from the code. Its
**Process** section has the validation commands, code layout and review
criteria, which apply to cleanup work as well as new features.
